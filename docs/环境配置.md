# 环境配置说明

本文说明「拾光」在本地开发与生产部署时需要的**全部**环境配置，配套文件：

| 文件 | 作用 |
| --- | --- |
| `.env.example` | 前端环境变量模板（复制为 `.env.local`） |
| `backend/.env.example` | 后端环境变量模板（复制为 `backend/.env`） |
| `backend/requirements.txt` | Python 依赖清单 |
| `package.json` / `package-lock.json` | Node 依赖清单（锁定版本） |
| `DEPLOY.md` | 生产部署步骤与运维命令 |

> 仓库中不含任何真实密钥。所有 `.env` 均被 `.gitignore` 忽略，只提交 `.env.example`。

## 一、运行环境

| 组件 | 版本要求 | 说明 |
| --- | --- | --- |
| Node.js | ≥ 20，推荐 22 LTS | 前端构建与运行 |
| Python | ≥ 3.10 | 后端（FastAPI） |
| MySQL | 8.0+ | 业务库，字符集 `utf8mb4` |
| ffmpeg | 任意较新版本 | 视频元信息、关键帧、封面抽帧（缺失则视频功能降级） |
| nginx | 1.18+ | 生产环境静态直出 + 反向代理 |

## 二、前端环境变量（`.env.local`）

| 变量 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- |
| `NEXT_PUBLIC_SITE_TITLE` | 否 | 拾光 | 站点标题 |
| `NEXT_PUBLIC_SITE_URL` | 否 | — | 站点地址，RSS 与分享链接使用 |
| `NEXT_PUBLIC_SITE_AUTHOR` | 否 | — | 作者名 |
| `NEXT_PUBLIC_SITE_AUTH_ENABLED` | 否 | `true` | 是否启用中间件登录校验 |
| `NEXT_PUBLIC_SITE_AUTH_USER` / `_PASS` / `_TOKEN` | 否 | `admin` / `admin` / `dev-auth-token` | 演示级凭据与 Cookie 值 |
| `NEXT_PUBLIC_SOCIAL_GITHUB` / `_GITEE` / `_EMAIL` | 否 | — | 社交链接 |
| `NEXT_PUBLIC_ICP_NAME` / `NEXT_PUBLIC_MOE_ICP_NAME` | 否 | — | 备案信息，留空不显示 |
| `BACKEND_URL` | 否 | `http://127.0.0.1:8000` | `next.config.ts` 里 `/api`、`/media` 的重写目标 |

## 三、后端环境变量（`backend/.env`）

| 变量 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- |
| `MYSQL_HOST` | 是 | `127.0.0.1` | 数据库地址 |
| `MYSQL_PORT` | 是 | `3306` | 数据库端口 |
| `MYSQL_USER` | 是 | `root` | 账号（生产建议独立账号，仅授权本库） |
| `MYSQL_PASSWORD` | 是 | 空 | 密码 |
| `MYSQL_DATABASE` | 是 | `shiguang` | 库名，字符集需为 `utf8mb4` |
| `DEEPSEEK_API_KEY` | 否 | 空 | 多模态识图与文案生成；留空则走本地推断（功能降级但不报错） |
| `DEEPSEEK_MODEL` | 否 | `deepseek-chat` | 模型名 |
| `AMAP_KEY` | 否 | 内置一把演示 key | 高德 **Web 服务** key：路线沿真实道路绘制、城市地理编码；缺失时路线退化为站点直连 |
| `TTS_VOICE` | 否 | `zh-CN-XiaoxiaoNeural` | edge-tts 音色 |
| `TTS_RATE` / `TTS_VOLUME` | 否 | `-8%` / `+0%` | 语速与音量 |
| `FFMPEG_PATH` | 否 | 自动探测 | 指定 ffmpeg 可执行文件路径 |
| `VIDEO_KEYFRAMES` | 否 | `6` | 每个视频抽多少关键帧 |
| `MAX_VIDEO_MB` | 否 | 见 `config.py` | 单个视频体积上限 |
| `DEMO_OWNER_USER` / `DEMO_OWNER_PASS` | 否 | 空 | 种子脚本写演示内容用的账号 |
| `NETEASE_COOKIE` / `TENCENT_COOKIE` / `KUGOU_COOKIE` | 否 | 空 | 音乐平台 Cookie（仅服务端使用，等同账号凭证） |

## 五、首次启动步骤

```bash
# 1. 数据库
mysql -uroot -e "CREATE DATABASE shiguang CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"

# 2. 后端
cd backend
cp .env.example .env          # 填数据库连接
python -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python -c "from db import init_db; init_db()"   # 建表
# 若从旧版本升级，按需执行幂等迁移脚本
.venv/bin/python migrate_media_comments.py
.venv/bin/python migrate_comment_owner.py
.venv/bin/python migrate_route_geometry.py
.venv/bin/python migrate_user_profile.py
.venv/bin/python migrate_weather_city.py
.venv/bin/python migrate_guide_reactions.py
.venv/bin/python migrate_video_poster.py
.venv/bin/uvicorn main:app --host 127.0.0.1 --port 8000

# 3. 前端
cd ..
cp .env.example .env.local
npm ci
npm run dev                   # 开发；生产用 npm run build && npm start
```

Windows 直接双击 `start.bat`（自动检查构建、起后端、开浏览器）。

## 六、常见启动问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| `Form data requires "python-multipart"` | 依赖缺失 | `pip install -r requirements.txt` |
| `ECONNREFUSED 127.0.0.1:8000` | 后端没起或端口不同 | 检查 uvicorn 进程与 `BACKEND_URL` |
| 页面 401 / 反复跳登录 | Cookie 过期或中间件开启但未登录 | 重新登录；或临时 `NEXT_PUBLIC_SITE_AUTH_ENABLED=false` |
| 语音按钮无反应 | 非 HTTPS 环境，浏览器不提供麦克风 API | 用 `https://` 或 `localhost` 访问 |
| 视频缩略图黑框 | 未安装 ffmpeg，未能抽首帧封面 | 安装 ffmpeg 后跑 `migrate_video_poster.py` |
| 路线是直线 | 未配置 `AMAP_KEY` 或境外坐标 | 配置高德 key；境外路线本就是示意弧线 |
| 上传报 413 | 超过体积上限 | 调整 `MAX_VIDEO_MB` 与 nginx `client_max_body_size` |

## 七、生产部署要点

见 [`DEPLOY.md`](../DEPLOY.md)。最需要记住的一条：**2 核 2 G 的机器上不要跑 `next build`**，
改为本机构建后只上传 `.next` 产物（已剔除 dev/cache，约 16 MB），服务器只做 `npm ci` 与 `next start`。
